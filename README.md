# Mini Catalog App

## Project Description

Mini Catalog App is a simple mobile application developed using Flutter as part of a mobile development training program.
The purpose of this project is to demonstrate the basic structure of a Flutter application including widget usage, page navigation, data modeling, and simple UI design.

The application displays a list of products in a catalog format and allows users to view product details and simulate adding items to a cart.

---

## Features

* Product list displayed using **GridView**
* Product detail page
* Page navigation using **Navigator**
* Data passing between pages using **Route Arguments**
* JSON data parsing using **Model classes**
* Simple cart simulation
* Clean and basic Flutter UI design

4. Run the application
